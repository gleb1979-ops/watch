Кабинет владельца

Вы вошли как владелец и можете изменять каталог.

Включайте только на личном устройстве. GitHub-токен хранится в браузере.

Добавлять и удалять часы может только владелец сайта. Для этого нужен личный токен GitHub. Он хранится в текущей сессии браузера и никуда не отправляется, кроме GitHub.

  1. Откройте создание токена.
  2. Название: watch. Срок: на ваше усмотрение (например, 1 год).
  3. Repository access: Only select repositories → выберите watch.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Нажмите Generate token, скопируйте его и вставьте ниже.

На общем или чужом устройстве не включайте эту опцию: токен хранится в браузере и предоставляет доступ к изменению каталога.
